# ⚡ Modern User Directory

This project is a sleek, high-performance CRUD (Create, Read, Update, Delete) dashboard built with **React** and **Styled-JSX**. It features a glassmorphic interface, real-time input sanitization, and a centralized state management flow.



## ✨ Features

* **Elite UI/UX**: Designed with a focus on typography, depth, and micro-interactions.
* **Adaptive Modals**: Unified form for both creating and editing users with smooth CSS transitions.
* **Intelligent Inputs**: 
    * Automatic numeric sanitization for phone numbers.
    * Mobile-optimized input modes.
* **Glassmorphism**: Backdrop blur effects and soft shadows for a premium feel.
* **Empty State Handling**: Graceful table behavior when no data is present.

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React.js |
| **Styling** | Styled-JSX (Scoped CSS) |
| **API Client** | Axios |
| **Backend** | JSON Server (Mock API) |
| **Icons/Type** | Inter Typeface & SVG Vectors |
